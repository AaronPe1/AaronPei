# AP1 个人摄影网站 · 最终交付版

2026.10.29。包含主预览与球场探索两种模式，保留原有网站，此文件包没有替换线上网站。

## 打开

Mac 上双击「启动网站.command」，保持终端窗口开启，浏览器会自动打开。按 Ctrl+C 可停止。

也可以在本文件夹运行：

```sh
python3 launch.py
```

直接双击 HTML 不适用于三维模块；请使用本地 HTTP 服务。

## 内容与原图

现有网站选片共44件：女超10.25有19件，FCC04.18有15件，FCC03.01有10件；其中38张单幅、6张组照。

- assets/originals：完整尺寸原始成片。43件为源文件逐字节复制，原有色彩、已有水印与元数据均保留，没有新增水印、重调色或AI重画。
- 21号组照：从用户PSD的合成画面按原尺寸2304×3840导出无损PNG，保留完整排版，不是1500px网站副本。
- assets/thumbs：导航用缩略图。主预览与原图查看都指向完整成片。
- 三维模式：读取同一份原图，显卡纹理按设备能力适配尺寸；场景融合与前景接地是展示效果，未改变原文件。可切换普通画面对比。
- originals-audit.json：原文件来源、输出路径、尺寸文件大小和SHA-256核验记录。43件直接复制文件已验证哈希与源文件一致。

原始成片合计746,438,027字节（约712MiB）。加载原图需要比缩略网页更长的时间；网页按当前作品加载，没有一次预读全部原图。

## 操作

主预览：按钮、方向键或拖动/滑动切换；底部胶片抽屉可展开收起，可按场上、人物、组照筛选；顶部比赛目录切换场次。

点击照片可完整查看；“原始尺寸”切换到像素尺寸，可滚动查看细节；“打开原文件”读取完整成片。

探索：拖动环顾，底部位置按钮沿底线移动；点击场内提示或“走近作品”观看；退出恢复原位，再返回主预览仍保留当前照片。无操作时导览淡出，移动或触碰唤回，“导览”可固定显示。

“门前一瞬”提供单张透视接地效果：下部纯草坪接到三维地面，人物仍保留为照片；支持对比普通画面和小范围轻移视角。该效果不是完整三维比赛重建。球场为作品展示环境，不是具体场馆复原。

## 文件与维护

- dist/：可独立运行的静态网站，全部图片、字体以外的图形与Three.js库本地提供，无外部CDN依赖。
- data.js：44件作品清单。
- app.js：主预览、比赛目录、原图查看。
- explore-loader.js：用户进入探索时才加载三维库。
- explore.js、stadium-detail.js、goal-projection.js：场景、细节、单张接地。
- vendor/THREE-LICENSE.txt：Three.js MIT许可。
- originals-audit.json：原图核验；brand-audit.json：标志核验；checks.json：交付检查摘要。

本地资料清单是交付审计文件。部署网站内容时使用dist目录。
